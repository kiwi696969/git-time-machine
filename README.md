# Git-代码时光机 · 微信聊天动画

ICT 大赛云赛道赛题 1.4：用 Git 管理"微信聊天动画"的代码版本。

## 作品内容

- `index.html`：手机尺寸 375×720 的微信风格聊天界面（单文件，纯 HTML/CSS/JS）。
  - **v1** 静态聊天界面：顶部"码道小助手"标题栏，对方左侧白气泡、我右侧绿气泡（#95ec69，圆角 8px），首版两条静态消息"在吗？ / 在的，怎么啦？"
  - **v2** 消息自动播放动画：JS 让 7 句对话脚本逐条自动弹出，对方发言前先显示"正在输入"三点动效，并自动滚动到底部，整体循环播放
  - **v3** 细节优化：灰底圆角药丸时间分割线、气泡朝向头像的小尾巴、柔和阴影与更舒服的绿色、对方正在输入状态变绿并带省略号动效
  - 还经历了一次"改坏再回退"：把绿色气泡改成刺眼的红色（`#ff5b5b`）后用 `git checkout -- index.html` 无损回退

## 本地版本管理练习（第三章）

| 命令 | 作用 |
|------|------|
| `git init` | 建立仓库 |
| `git add` / `git commit` | 存档（快照） |
| `git log --oneline --graph` | 查看提交历史 |
| `git checkout` / `git reset --hard` | 切换版本 / 回退 |

提交历史：

```
* b6f19df v3 优化细节与主题
* 08ccf4b v2 消息自动播放动画
* 48043f2 v1 静态聊天界面
```

## 远程协作练习（第四章）

- 将本地仓库推送到 GitCode 远程仓库
- 拉取最新 main 分支并开出特性分支
- 在特性分支上开发并提交
- 推送分支、创建合并请求完成评审合入

## 运行方式

直接用浏览器打开 `index.html` 即可预览聊天动画。
